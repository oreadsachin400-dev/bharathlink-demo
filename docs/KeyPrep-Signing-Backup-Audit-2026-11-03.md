## Current conclusion
**Original private APK-signing key NOT RECOVERED.**
**Existing installed APK certificate MATCHED.**
**Safe in-place update BLOCKED.** These are independent facts.

A certificate match does not permit reconstructing a private signing key. Android signing credentials are unrelated to non-exportable, app-scoped AndroidKeyStore keys created for device messaging.
