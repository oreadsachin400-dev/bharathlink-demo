# Chat Simulation Lab V5 Android TEST

**Offline, SIMULATED ONLY**; NOT WhatsApp and cannot alter authentic WhatsApp messages.

Features: multiple independent demo conversations, per-chat search/edit/delete/add, exported TXT copy import, backup/restore all demo chats, legacy V4 JSON restore. Personal chat data and backups are not included in this project.

Separate Android application ID `app.chatsimulation.lab.v5` allows V4 and V5 to coexist without uninstall. Android WebView + local assets. No INTERNET or SMS permission. Uses Android SAF for backup and restore. Debug APK is TEST only.
